## 현재 적용 규칙과 과거 규칙 구분

- 아이템 데이터의 Hold 보존 기능과 무게추 Hold 금지는 별개다. 무게추는 보관하지 않는다.
- M은 해당 고정에서 발생한 삭제 점수를 한 번 2배로 만든다. 이미 얻은 하강 점수는 다시 배가하지 않는다.
- F로 5줄 이상 삭제하면 4줄 6,000점 + 초과 줄당 1,000점을 기본값으로 사용한다.
- 무게추의 1.5배 속도는 현재 점수 배율에도 반영된다. 구현 사실이며 별도의 회의 승인 기록이 있다는 뜻은 아니다.
- 과거 기록의 80/100/120 속도 증가 상수와 초기 생성 좌표 규칙을 최신 규칙과 혼용하지 않는다.
- 일반 블록의 O 문자 표시와 JavaFX 사용은 모순이 아니다. JavaFX 창에서 문자 기반 게임 화면을 표시한다.
