박제상(보드), 박서상(테트로미노), 정승우(게임 시스템·UI)의 작업을 실제 Git 이력에 근거해 정리한다.

## 기록 기준

- 정리일: 2026-10-26. 원격 `origin/develope` 확인 기준: `acab7f5` (PR #19 병합).
- 아래 5개 구간은 실제 커밋 날짜를 기준으로 사후 정리한 개발 단계다. 당시 확정된 스프린트 시작일·종료일이나 회의 일정으로 주장하지 않는다.
- 날짜는 Git 작성 일시의 한국 시간(+09:00)이다. 구현 커밋 날짜와 PR 병합 날짜를 구분한다. 커밋 날짜가 실제 작업 시작일을 뜻하지는 않는다.
- 근거 우선순위: 실제 변경 파일·커밋 및 병합 이력 → 당시 문서 → 사용자 제공 개발노트 요약·작업 설명.
- GitHub PR 링크는 저장소의 실제 병합 커밋 메시지에서 확인한 번호다. PR 본문의 논의·승인자·리뷰 횟수는 조회하지 않았으므로 추정하지 않는다.
- 배포·아이콘·커버리지는 현재 작업 트리에서 검증한 미커밋 산출물이다. 원격 통합 완료와 구분한다.

## 앞으로의 운영

작업 등록 → 담당 배정 → 구현·문서화 → 테스트 → PR 검토·통합 → 결과 기록 순서로 관리한다.
이는 앞으로 적용할 운영 기준이며 과거에 모든 절차를 수행했다는 진술이 아니다.

상태는 **대기 / 진행 / 구현·검증 완료(통합 전) / 통합 확인 / 확인 필요**로 구분한다.
PR 병합만으로 테스트 통과·리뷰 승인·요구사항 전체 충족을 단정하지 않는다.
작업 ID는 문서 내부 식별자이며 GitHub Issue 번호가 아니다.

업무 보드 도구의 실제 생성·이력은 아직 확인하지 않았다. GitHub Projects 또는 Trello에서
[작업 카드 양식](templates/task.md)으로 등록하고 문서·PR·테스트 보고서를 연결해야 한다.
이 문서 작성 자체를 외부 작업 관리 도구 운영의 증거로 제시하지 않는다.
