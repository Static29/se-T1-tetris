## 문제 발생 및 해결

### 다른 환경에서의 Java 버전 오류

- 발생 상황: 다른 사람의 개발 환경에서 프로젝트를 실행하는 과정에서 Java 버전 관련 오류가 발생했습니다.
- 프로젝트 기준: JDK 21을 사용합니다.
- 처리 결과: 버전 관련 문제를 해결했다고 팀장이 확인했습니다.
- 추가 기록 필요: 오류 메시지, 변경 전후 Java 버전, 실제 적용한 설정 또는 명령어. 정확한 해결 절차는 아직 전달되지 않아 추정해서 기록하지 않습니다.
- 재발 시 확인 항목: `java -version`, `.\gradlew.bat --version`, `JAVA_HOME` 및 IDE의 프로젝트 JDK 설정을 비교합니다. 이는 확인 절차이며 이번에 실제 수행한 조치로 단정하지 않습니다.

### Block 추가 후 테스트 확인

- 최신 `games`를 받은 뒤 `develope`와 파일 내용에 차이가 없음을 확인했습니다.
- 검증 명령: `.\gradlew.bat clean test`
- 결과: 기존 테스트 26개 통과, 실패·오류 0개, `BUILD SUCCESSFUL`.
- 검증 대상: `games`의 `28c2d64`; 당시 `develope`의 `8669fec`와 파일 내용 동일.
- `Block.java`를 포함한 컴파일 오류는 재현되지 않았습니다. 이 결과가 새 블록의 이동·회전 기능 전체를 검증한 것은 아닙니다.
- 위 자동 테스트는 로컬에서 확인한 결과이며, 다른 사람 환경에서의 테스트와 구분합니다.
